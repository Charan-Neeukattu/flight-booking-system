# SkyBooker - Frontend

React + Vite frontend for the SkyBooker Flight Booking application.

## Tech Stack
* **React 19**
* **Vite**
* **Tailwind CSS**
* **React Router DOM v7**
* **Framer Motion**
* **Lucide React**
* **Axios**

## Development
```bash
npm install
npm run dev
```

Runs on [http://localhost:5173](http://localhost:5173).

## Production Build
```bash
npm run build
npm run preview
```

For the complete project setup, database, and backend documentation, see the [Root README](../README.md).
